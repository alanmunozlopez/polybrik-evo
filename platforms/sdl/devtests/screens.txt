# Cases for brick-suite.sh, one per line:  name  times_ms  keys  [check]
# times_ms: one screenshot time, or several separated by commas (<name>-1.png, <name>-2.png, ...).
# keys: the --keys spec ("-" for none): "ms:id" or "ms:id:hold_ms", Mini ids (up, enter, rec, plus1,
#   screen1..screen8 for the eight keys under the screen, the module ids pattern, song, file, ...) or
#   pad.<input>. Keep 150 ms or more between presses of the same key.
# check: none for a screen case: the run uses --sim-clock (firmware time is one ms per loop), so each
#   screenshot is the same frame on every run and is compared with golden/<shot>.png.
